# DARK GPT v2.1

Background voice assistant (Urdu/English) with Gemini, floating Orb, battery alerts.

Setup:
1. Settings > E. AI: Gemini API key paste karein, Save dabayein.
2. "Model list" dabayein taake aapke account ke models dikhen. Model naam badal kar Save kar sakte hain.
3. Settings > F. Permissions: Microphone, Notifications, Display over other apps allow karein.
4. Battery: "Unrestricted" aur Autostart allow karein.
